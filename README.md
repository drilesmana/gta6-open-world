An original, static-browser crime story set in Marisol Bay: a compact coastal city with 36 blocks, palm-lined promenade, pastel shopfronts, downtown towers, beach and freight pier. All environment art, characters, vehicles and audio are generated by the game's source. The only third-party runtime is the locally vendored Three.js build, with its license retained.

## Play

Run `node serve.ts` and open `http://localhost:8080`. No build or external runtime request is needed. For a software-rendered VM use `http://localhost:8080/?lite=1` to disable shadows and reduce resolution. Desktop keyboard and mouse are required.

- WASD / arrows: walk or drive; Shift: sprint.
- Mouse: look; left click: punch or shoot. R: reload.
- F: enter, steal or leave a nearby car.
- E: talk, collect or hand over an objective, including while driving.
- Space: brake / handbrake. H: horn. C: recenter camera. Wheel: zoom.
- M: city map. Q: synthesized radio. Escape: pause / save menu.

Start beside the Tiga Saudara garage. Follow the gold diamond and press E for Bima's briefing. Complete Hot Parcel, The Courier and Sunset Run to reclaim the garage, then continue exploring. Deliveries replenish some health and ammunition. Extra courier gigs and loose cash cases reward exploration. Committing crimes brings police cruisers and officers; break sight and gain distance to lose unpinned wanted levels. Mission chases keep their minimum stars until completion.

Progress, cash, equipment and completed story chapters save in localStorage. Active jobs restart from their briefing after loading; vehicles and the live population are not serialized. New Game replaces the existing save.

## Verification

`python tests/playtest.py` runs the browser integration suite with Python Playwright installed separately. It exercises movement, carjacking, driving, combat/reload, map, pause, police response/escape, all story stages, save/reload, death/recovery and timeout/retry. Its state fixtures position the player near objectives and construct repeatable vehicle impacts; this is not an unattended full-route skill playthrough. See `tests/last-run.json` and `QA.md` for actual evidence and limitations.

The four JPEGs under `screenshots/` are direct 1280×720 browser captures of gameplay, without compositing or retouching. The first filename is the cover. Capture positions were staged using live game objects; all visible meshes, HUD and effects are rendered by the shipped code.

## Package

Use Node 22 with native TypeScript stripping enabled (or a newer compatible Node):

```
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The entrypoint copies `game/`, `screenshots/` and builds `dossier.json` through the unchanged kit library. Only those artifacts are handed in. The game has no npm dependencies or build step. Tests and documentation remain outside the static game.

Before submission, the entrant must verify the sealed make.fun recordings and required run record. Local game checks cannot certify transcript authorship or recording eligibility. No push or submission is performed by this build.
